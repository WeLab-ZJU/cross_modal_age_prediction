# Historical References — Not Runnable Launchers

This directory preserves historical documentation and shell experiment
records from the source directories.

- `human/` corresponds to the original `codes/`.
- `mouse/` corresponds to the original `codes_mouse/`.
- `.sh.txt` files are historical text, not current executable templates.
- Personal server paths have been replaced with placeholders such as
  `<HUMAN_CODE_ROOT>`, `<HUMAN_DATA_ROOT>`, `<HUMAN_OUTPUT_ROOT>`, and
  `<PRETRAINED_ROOT>`.
- Hyperparameters and repeated assignments are retained. Do not assume
  that every historical experimental configuration is valid.
- External repository links, anonymization claims, environment details,
  licensing statements, and methodological descriptions in historical
  READMEs have not been verified and are not new publication claims.
- Chinese explanatory comments were translated for the English edition;
  historical commands and parameter values were not changed.

Start with the root README, `run.py`, `scripts/`, and `mouse/demo/`.
