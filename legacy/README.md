# Historical Experiment Configurations

These `.sh.txt` files are configuration references, not runnable launchers.

- `human/` contains human eye experiment settings.
- `mouse/` contains mouse eye and multimodal experiment settings.
- Paths such as `<HUMAN_DATA_ROOT>`, `<HUMAN_OUTPUT_ROOT>`, and
  `<PRETRAINED_ROOT>` are placeholders.
- Repeated assignments use the last assigned value. Review GPU counts,
  image sizes, and supported arguments before reusing a configuration.

Use the root README, `run.py`, `scripts/`, and `mouse/demo/` for current
commands. Configuration caveats are listed in `docs/USAGE_NOTES.md`.
